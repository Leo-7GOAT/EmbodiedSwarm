# EmbodiedSwarm

A personal robotics project for mobile manipulation, planning and control.

## Platform

- differential-drive mobile base
- Franka Panda 7DoF arm as the first arm target
- MuJoCo first
- ROS2 / MoveIt2 / ros2_control later

The planned system is a mobile manipulator: a mobile base combined with a
6DoF or 7DoF robotic arm. W01 only fixes the initial route and interface
boundaries.

## Current status

- repository initialized
- system architecture defined
- task milestones defined

Simulation, navigation, grasping, and robot control are not implemented yet.

## Roadmap

- robot model and state interface
- 2D navigation baseline
- manipulation planning
- mobile manipulation
- multi-agent extension
